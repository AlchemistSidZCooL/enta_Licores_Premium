# Venta Licores Premium - Escaparate Digital Dark Luxury

Proyecto web de catálogo interactivo y landing pages individuales para la colección privada de licores premium en Madrid.

## 🌟 Características
- **Arquitectura Dark Luxury:** Interfaz basada en tonos oscuros (`#0d0a14`), acentos dorados (`#d4af37`), y tipografías *Playfair Display* + *Outfit*.
- **Catálogo Multi-Página:** 10 landing pages dedicadas con checkout directo vía WhatsApp.
- **Renders de Estudio 1024x1024:** Procesamiento automatizado con `rembg` e iluminación radial en pedestal para cada botella individual sin fondos ruidosos ni manos.
